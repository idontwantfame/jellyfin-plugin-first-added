First Added

Preserve movie and episode date-added timestamps when files are replaced or upgraded.

Select libraries and save, then initialize to record their current Jellyfin dates. Enable preservation and save to protect future imports and upgrades. Dates lost before initialization cannot be recovered automatically.

Libraries

Newly selected libraries and item types need initialization before preservation starts. Metadata locks are respected. Provider IDs identify titles across file replacements; unmatched or conflicting identities are skipped.

Dates and recovery

Rollback revokes initialization for all libraries and restores backed-up dates still owned by this plugin. Locked items and subsequent manual changes are skipped. Failed restores can be retried. Initialize again only when you intend to resume preservation.
